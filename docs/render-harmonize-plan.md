# B안: 글자는 폰트로, 장면은 모델로 (render -> harmonize)

## 왜 바꾸나

글리프 조건 파일럿 세 가지가 모두 글리프를 베끼지 못했다.

| 방식 | 캡션 글자 그대로 | 캡션 글자 가림 |
|---|---|---|
| omni (v1, step 5000) | 글리프와 섞임, 0/10 정확 | - |
| 채널 붙이기 ch1 (step 5245) | 10/10 프롬프트 글자 | - |
| 채널 붙이기 ch2 (step 2650 / 3001) | 10/10 프롬프트 글자 | 0/10 글리프, 잡글자 (dual CER 0.98) |

LoRA만 학습해서는 모델이 "글리프를 그대로 옮긴다"를 배우지 않았다. 학습 없는 길로 글자 정확도를 먼저 확보한다.

## 방식

1. **장면 생성.** Z-Image Base(28스텝, guidance 4)로 장면을 만든다. 프롬프트의 글자 자리는 빈 간판·빈 라벨처럼 "글자 없는 면"으로 바꾼다. 예: `"약국"이라고 적혀 있음` -> `글자가 없는 빈 면`.
2. **글자 자리 정하기.** `scripts/glyph.py`의 장면별 기본 배치를 쓴다. 장면에 빈 면이 생기면 그 면에 맞춘다(밝기 균일 영역 탐색, 실패하면 기본 배치).
3. **글자 그리기.** 폰트로 정확히 그린다.
   - 폰트: OFL 한글 폰트 몇 개(Noto Sans/Serif KR, 나눔고딕, 나눔명조, 검은고딕 계열). 프롬프트의 "굵은", "손글씨" 같은 말로 고른다.
   - 색: 프롬프트의 색 단어(금색, 흰색, 검은색 ...)를 RGB로. 없으면 배경과 대비가 큰 색.
   - 크기: 상자에 맞춰 최대 크기, 줄바꿈은 어절 단위.
   - 붙이기: 약한 원근(상자 네 모서리), 그림자·외곽선은 프롬프트에 있을 때만.
4. **다듬기(harmonize).** Z-Image inpaint 파이프라인(`pipeline_z_image_inpaint.py`, diffusers에 있음)으로 글자 둘레만 다시 그린다.
   - 마스크: 글자 상자를 조금 키운 띠(글자 획 자체는 마스크 밖). 조명·질감·가장자리만 섞인다.
   - strength 0.3 / 0.5 / 0.7 세 값을 비교.
   - 선택: 전체를 img2img strength 0.15~0.25로 한 번 더 -> 획이 깨지는지 OCR로 확인. 깨지면 이 단계는 끈다.
5. **검사.** 두 OCR(`--ocr dual`)이 목표 글자를 읽지 못하면 4단계 strength를 낮춰 다시. 그래도 안 되면 3단계 결과를 그대로 쓴다.

새 학습은 없다. GPU는 생성 시간만 쓴다.

## 비교 대상과 통과 기준

같은 프롬프트 220개(`eval/prompts.jsonl` + `eval/prompts_unseen_syllables.jsonl`), 시드 42.

| 지표 | 기준 | 비교 |
|---|---|---|
| unseen 단어 dual CER | 0.05 이하 | r64 v2: 0.312 |
| 정확히 맞춤 (dual) | 90% 이상 | r64 v2: 30% |
| unseen 음절 20개 | 사람 판정 18개 이상 | 측정 못 함 |
| 자연스러움 | 사람 판정 20장, "붙여 넣은 티" 5장 이하 | r64 v2 같은 20장 |

자연스러움은 사람이 본다. VLM은 판정에 쓰지 않는다(글자를 짐작으로 맞다고 한 전례).

## 순서

1. `scripts/render_harmonize.py`: 1~5단계, 입력은 prompts jsonl, 출력은 `eval_baseline.py`와 같은 폴더 형식(images/, scores.jsonl, report.json).
2. 20개로 시험: strength 3개 x 마스크 띠 2개. 사람 판정용 시트(원본 장면 | 글자 얹음 | 다듬음) 만들기.
3. 가장 나은 설정 하나로 220개 전체 + dual 채점 + r64 v2와 한 표.
4. 통과하면 이 방식을 기본 경로로. 자연스러움이 기준 미달이면, 그때 r64 v2 LoRA를 4단계 inpaint에 붙여 본다(장면에 녹아드는 글자 질감 학습분 재사용).

## 위험

- 빈 면을 못 만드는 장면(책 표지, 포스터 배경이 복잡한 경우) -> 기본 배치로 덮어쓰면 붙인 티가 남.
- 곡면(병 라벨)·강한 원근 -> 단순 원근 변환으로 부족할 수 있음. 1차에서는 평면 장면만 통과 판정에 넣고 곡면은 따로 센다.
- inpaint strength가 높으면 획을 건드림 -> 5단계 OCR 검사로 막음.

## 정리

- ch2는 step 3285에서 멈춤(체크포인트 남음). 글리프 실험 결과는 `paper/runs/glyph-*`에 있음.
- r64 v2 LoRA는 비교 기준으로 그대로 둔다.
